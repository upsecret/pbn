# Phase 4. 백링크 빌딩 (Week 2~6, 병행)

> **목표**: 도메인 권위(DR) 향상으로 SERP 1~3위 견인
> **우선순위**: ★★★★★
> **예상 효과**: +15~30단 (가장 큰 단일 효과)

---

## 4.1 백링크의 중요성

SERP 1~3위가 모두 **isweb.co.kr 서브도메인**인 이유:
- isweb 모도메인이 **DR 60+ 수준** (추정) — 모회사 권위 후광
- 신생 도메인이 추월하려면 **양질의 백링크 누적** 필수

timesharelink는 신생 .com → **백링크 우위 없이는 구조적 한계**.

## 4.2 보유 PBN 자산 활용 (1차, 즉시)

### PBN 자산 점검 (Week 2 Day 1)

```
list_pbn_domains          → 보유 PBN 도메인 전체 목록
list_pbn_worksheets       → 운영 시트 목록
get_pbn_worksheet_content → 시트별 도메인 상태 / DR / 인덱싱
backlink_list             → 현재 backlink 운영 상태
```

### PBN 배포 전략

| 배치 | PBN 수 | 콘텐츠 | 앵커 텍스트 비율 |
|---|---|---|---|
| Batch 1 (Week 2) | 5~10개 | 주소모음 관련 글 1편 | 60% 브랜드, 30% URL, 10% 키워드 |
| Batch 2 (Week 3) | 5~10개 | 링크모음 관련 글 1편 | 50% 브랜드, 30% 부분 키워드, 20% URL |
| Batch 3 (Week 4) | 5~10개 | 비교/리뷰 글 1편 | 40% 브랜드, 40% 부분 키워드, 20% 정확 키워드 |
| Batch 4 (Week 5~6) | 자연 확장 | 다양한 주제 | 자연 분포 |

### 앵커 텍스트 분포 원칙

**과최적화 회피**: "주소모음" 정확 일치 앵커 비율을 **전체의 10% 이내**로 유지.

| 앵커 유형 | 비율 | 예시 |
|---|---|---|
| 브랜드 앵커 | 40~50% | "타임쉐어링크", "TimeShareLink", "timesharelink" |
| URL 앵커 | 20~30% | "www.timesharelink.com", "timesharelink.com" |
| 부분 키워드 | 15~25% | "주소모음 사이트", "검증된 링크모음", "안전한 주소모음" |
| 정확 일치 | 5~10% | "주소모음", "링크모음" |
| 자연어 | 5~10% | "여기에서", "이 사이트", "자세히 보기" |

### PBN 콘텐츠 생성 도구

```
generate_pbn_content     → AI 콘텐츠 초안
preview_pbn_content      → 배포 전 미리보기
upload_pbn_content       → WordPress 자동 업로드
edit_wp_content          → 사후 수정
add_pbn_to_sheet         → 시트 기록 (트래킹용)
```

## 4.3 자매 사이트 상호 링크 (Week 2~3)

jusomoeum 프로젝트 내 자매 사이트들과 자연스러운 상호 링크.

### 후보 사이트 (jusomoeum 내)
- isweb-jusois, isweb-jusolook, isweb-jusomi, isweb-jusomoeum, isweb-jusotown
- jusominet, jusoguide, jusoguidecom, jusotown
- jusolink, juso-moeum, juso-top
- link-bridge, link-farm, labslink, nettensor

### 상호 링크 전략
- **풋터 "함께 이용하면 좋은 사이트"** 섹션에 3~5개 자매 사이트
- **본문 자연 인용** — "함께 보면 좋은 자매 서비스 [주소look] 추천" 같은 형태
- **블로그 글 내 비교/추천** — 카니발리제이션 회피하며 자연스럽게

### 주의 사항
- 모두 동일 IP/Host로 연결되면 **링크 네트워크 감지** 위험
- 각 자매 사이트의 호스팅 분산 확인 (Cloudflare 다른 zone)
- 풋터 위젯 한 번에 모든 사이트 노출 금지 → 회전식 또는 카테고리별

### 4.4.1 디렉토리 등록

| 디렉토리 | 비용 | DR | 우선순위 |
|---|---|---|---|
| 네이버 검색 등록 | 무료 | 매우 높음 | ★★★★★ |
| 다음 검색 등록 | 무료 | 높음 | ★★★★ |

### 4.4.2 게시판/커뮤니티 자연 인용
- 클리앙, 뽐뿌, 디시 등 IT 게시판에서 **검증 시스템 차별점** 자연 인용
- 직접 광고/스팸 금지, 도움 콘텐츠로 접근
- 닉네임 분산 (1인 다계정 금지)

### 4.4.3 게스트 포스팅
- IT/보안 블로그에 "안전한 주소모음 사이트 식별법" 등 기고
- 작가 프로필 또는 본문 내 1~2회 링크

### 4.4.4 Q&A 사이트
- 네이버 지식인, Yahoo 답변 등에서 관련 질문에 답변 + 자연 인용
- 답변 품질 우선, 링크는 보조

## 4.5 백링크 모니터링

### 주간 추적 항목

```
ahrefs_dr_history (target=timesharelink.com)
  → DR 추이 (Week 1: 시작점, Week 6: +5~10 목표)

ahrefs_referring_domains (target=timesharelink.com)
  → 참조 도메인 수 추이

ahrefs_backlinks (target=timesharelink.com)
  → 신규 백링크 발견

anchor_analysis
  → 앵커 텍스트 분포 점검 (과최적화 경고)

referring_domains
  → 신규 발견 자매 백링크
```

### 위험 신호 모니터링
- 정확 일치 앵커 비율 15% 초과 → **즉시 감속**
- 동일 IP 백링크 30% 초과 → **분산 필요**
- 갑작스러운 백링크 급증 (한 주 100+) → **자연스러움 조정**
- 네거티브 SEO (스팸 백링크 공격) → Disavow 준비

## 4.7 윤리/리스크 관리

### PBN 사용 시 주의
- Google 가이드라인상 PBN은 **명백한 위반**
- 그러나 한국 SERP 상위 다수가 PBN/링크빌딩 활용 중 → 경쟁 환경 반영
- **수동 패널티 시 회복 어려움** → 다음 원칙 준수:
  1. PBN 콘텐츠는 **고품질** (자동 스피닝 금지, 사람이 읽을만한 글)
  2. 호스팅·IP·등록자 정보 분산
  3. 발신·수신 패턴 자연스럽게
  4. 정확 일치 앵커 절제
  5. 점진적 확장 (한 번에 폭증 금지)

### 백업 플랜
- 화이트햇 백링크 비중을 30% 이상 유지 → PBN 일부 무효화 시 완충
- 자연 트래픽·브랜드 검색량 확보 → 인위적 신호 의존도 ↓
