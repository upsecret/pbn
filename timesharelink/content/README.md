# 검증 로그 데이터 (주소·링크검증 업데이트 로그)

## 파일

- **`verification-update-logs.jsonl`** — 한 줄에 JSON 객체 하나씩 추가합니다. DB 없이 이 파일만으로 목록을 관리합니다.

## 필드 (각 줄의 JSON 키)

| 필드 | 설명 | 예시 |
|------|------|------|
| 제목 | 업데이트 제목 | `주소검증 페이지: URL 구조 분석·리다이렉트 추적 안내 추가` |
| 업데이트 날짜 | YYYY-MM-DD | `2026-03-06` |
| 버전/차수 | 차수·버전 표기 | `1차`, `v1`, `Phase 1` |
| 카테고리 | 아래 5개 중 하나 | `URL 구조 검증` |

### 카테고리 (선택값)

- URL 구조 검증
- 리다이렉트 검증
- 콘텐츠 일치 검증
- 도메인/서버 응답 검증
- 결과 해석 기준

## 사용처

- **홈** — “업데이트 로그” 섹션: 최신순 **최근 7건**만 표시
- **검증로그 페이지** (`/검증로그`) — JSONL **전체 목록** 리스트 (날짜 최신순)

새 항목은 파일 **맨 위(첫 줄)** 에 한 줄씩 추가하면 됩니다.
